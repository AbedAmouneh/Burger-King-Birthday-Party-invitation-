# Fonts in this directory

Both files are bundled only so `app/opengraph-image.tsx` can render the share
card with the site's own typefaces. Satori (which powers `ImageResponse`) cannot
read WOFF2, so these are TTFs.

- **Lilita One** by Juan Montoreano, SIL Open Font License 1.1
  https://fonts.google.com/specimen/Lilita+One
- **Press Start 2P** by CodeMan38, SIL Open Font License 1.1
  https://fonts.google.com/specimen/Press+Start+2P

The OFL permits bundling and redistribution with the software.
